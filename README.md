# Payment_Processing_Service
Тестовое задание: Асинхронный сервис процессинга платежей Описание Необходимо реализовать микросервис для асинхронной обработки платежей. Сервис принимает запросы на оплату, обрабатывает их через внешний платежный шлюз (эмуляцию) и уведомляет клиента о результате через webhook
